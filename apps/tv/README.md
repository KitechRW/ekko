# EKKO TV

Initial target: Android TV / Google TV.

The TV experience prioritizes the broadcast:

- native HLS playback;
- no pause/seek controls;
- automatic reconnect and live-edge recovery;
- current program and clock time;
- viewer count;
- realtime chat display;
- repeated reactions sent with the remote;
- no chat text input.

Initial player technology direction: Kotlin + AndroidX Media3.
